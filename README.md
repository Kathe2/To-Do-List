# ✅ To-Do List App

Uma aplicação de lista de tarefas desenvolvida com **HTML, CSS e JavaScript**, criada durante o desafio **30 Days, 30 JavaScript Projects For Beginners** do canal *GreatStack*.

O projeto foi desenvolvido com o objetivo de praticar manipulação do DOM, armazenamento de dados no navegador e interação dinâmica com o usuário utilizando JavaScript puro.

---

## 📌 Sobre o projeto

O To-Do List App permite adicionar, concluir e remover tarefas de forma simples e intuitiva, ajudando na organização de atividades do dia a dia.

Durante o desenvolvimento, foram aplicados conceitos importantes como:

* Manipulação do DOM
* Eventos em JavaScript
* Armazenamento local com `localStorage`
* Criação dinâmica de elementos HTML
* Estruturação de lógica com JavaScript
* Interatividade no front-end

---

## 🚀 Funcionalidades

✔️ Adicionar novas tarefas

✔️ Marcar tarefas como concluídas

✔️ Remover tarefas da lista

✔️ Salvamento automático com `localStorage`

✔️ Interface simples e responsiva

✔️ Atualização dinâmica sem recarregar a página

---

## 🛠️ Tecnologias utilizadas

| Tecnologia   | Descrição                             |
